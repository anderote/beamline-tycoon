Staff Foundry

Six figurine designs for facility staff. Each card shows a close-up of all four roles for judging silhouette, proportion, shading, palette and face, plus a smaller in-context panel beside a real rfCavity at true game scale for the does-it-clash-with-the-machinery check. Both views use the game's exact lighting rig (ambient 0xfff5e6 @1.3, directional 0xffffff, PCFSoft shadows), the same 2:1 dimetric orthographic camera angle, and the same half-resolution pixelated render path — the close-up is only a closer camera, the way zooming in inside the game would be. Approve or reject each, then hit "copy verdicts".
